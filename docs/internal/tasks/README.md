# Task files

These are orchestration artefacts from the 1.0 rewrite: one file per unit of
work, written to be executed independently and reviewed as a diff.

They are a historical record, not user documentation and not a maintained
spec — the code and the [docs site](https://mhmd-sdghn.github.io/react-bottom-sheet/)
are the truth. `docs/internal/` is excluded from the published site.
